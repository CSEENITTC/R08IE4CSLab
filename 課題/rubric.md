# 全8回 演習採点ルーブリック (Grading Rubric)

- **作成担当**: `04_課題作成担当`
- **授業名**: 「Computer System Laboratory」
- **配点標準**: 1回あたり **100点満点**
  - **基本問題（必須課題）**: 70点満点（合格ライン: 50点以上）
  - **発展問題（推奨・応用課題）**: 30点満点（加点方式）

---

## 1. 採点の基本方針

1. **工学的正確性の評価**: 単にテストベンチの波形が一致するだけでなく、デジタル回路設計の原則（透過ラッチの非発生、同期イネーブル伝播、Moore型FSMによるグリッチ防止等）が遵守されているかを評価します。
2. **2段階評価システム**:
   - 基本問題のみを確実に完了した場合でも最高70点（合格水準）に到達できます。
   - 90分の演習時間内で発展問題まで意欲的に取り組んだ受講者には、最大30点の加点を行い、優秀な設計力を適切に評価します。

---

## 2. 共通評価基準（基本問題: 70点満点）

| 評価項目 | 配点 | 評価の観点 | 減点基準・失点要因 |
| :--- | :---: | :--- | :--- |
| **論理機能の正確性** | 35点 | 要求された論理機能・演算・状態遷移が網羅的に動作しているか。全テストケースをパスするか。 | 機能不良・コーナーケースのバグ (-10〜-25点) |
| **型安全性とビット幅整合** | 15点 | `Bool`, `UInt`, `SInt` の型、`.W` によるビット幅の明示が正確であるか。暗黙の切り捨てがないか。 | ビット幅不一致、無用なキャスト (-5〜-10点) |
| **ハードウェア構造の健全性** | 20点 | 意図しない透過ラッチ（`WireDefault` 不足）や、非同期クロック伝播などの重大な設計欠陥がないか。 | 透過ラッチの混入 (-15点)、非同期リップルクロック (-20点) |

---

## 3. 共通評価基準（発展問題: 30点満点）

| 評価項目 | 配点 | 評価の観点 | 評価ポイント |
| :--- | :---: | :--- | :--- |
| **拡張仕様の達成度** | 15点 | 仕様書で求められた拡張機能（フラグ生成、バイパス論理、パイプライン等）が正しく実装されているか。 | 拡張ロジックが機能仕様通りに完全に動作している |
| **コーナーケースへの配慮** | 10点 | 境界値（オーバーフロー、同時読み書きRAW競合、タイマ満了時等）で異常動作せず正しくハンドリングできているか。 | エッジケースでも破綻しない強固な論理構成 |
| **コードの可読性と設計作法** | 5点 | 階層化や信号命名が適切であり、回路の意図が第三者に明確に伝わる記述になっているか。 | 適切な識別子命名、コメント、構造の簡潔性 |

## 4. 回別の重点採点ポイント一覧

| 回 | 基本問題 (70点) 重点ポイント | 発展問題 (30点) 重点ポイント |
| :---: | :--- | :--- |
| **第1回** | 基本論理演算子 (`^`, `&`, `|`) による半加算器・全加算器の正確な回路記述 | `+&` による拡張加算、ビットスライス、縮約XOR (`xorR`) によるパリティ生成 |
| **第2回** | `WireDefault` による未定義値での透過ラッチ抑止とデコード表 | 優先度順位判定と全ビットORによる `valid` フラグの一貫性 |
| **第3回** | `clear` $\to$ `load` $\to$ `en` の優先度構造と $(N-1)$ でのラップ | カウンタ出力比較によるPWM出力波形のデューティ比正確性 |
| **第4回** | `PopCount` 等を用いた不正状態からの自己復帰論理の動作保証 | バイナリからグレイコードへの変換論理（ハミング距離1遷移） |

| **第8回** | `Mem` を用いた無遅延非同期読み出しとクロック同期書き込み | 同一アドレス同時アクセス時のRAWフォワーディングMUX回路 |
